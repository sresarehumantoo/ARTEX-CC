## HTB Forest at a glance

| Phase | What the agent did |
|-------|-------------------|
| **Recon** | nmap found a Windows Server 2016 DC for `htb.local`. An RPC null session leaked the full user list. |
| **Foothold** | `svc-alfresco` had Kerberos pre-auth disabled: AS-REP roast, cracked with hashcat and rockyou, WinRM, **user.txt** |
| **Domain Admin** | Account Operators, created a user, Exchange Windows Permissions (WriteDACL), DCSync, Administrator NTLM hash, pass-the-hash, **root.txt** |
| **Cleanup** | Restored the domain DACL, deleted the created user, removed uploaded scripts |

The agent also solved two tooling problems inline (PowerView failing under non-interactive WinRM, and the OpenSSL 3 MD4 deprecation) without human help.

The broader evaluation plan (tool-level, orchestration, end-to-end and safety evals) lives in [`docs/EVAL_PLAN.md`](https://github.com/SREsAreHumanToo/ARTEX-CC/blob/main/docs/EVAL_PLAN.md) in the repository.
